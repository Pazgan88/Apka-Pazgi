# Koledzy App

Pierwszy działający fundament aplikacji AI do zarządzania spiżarnią, żywieniem, treningami i postępami.

## Uruchomienie

```bash
npm install
npm run dev
```

Aplikacja będzie dostępna pod adresem `http://localhost:3000`.

## Etap 1

- Next.js + TypeScript
- responsywny interfejs mobilny
- ekran główny
- widok czatu AI
- widok spiżarni
- widok treningów
- widok profilu
- manifest PWA

Integracje Supabase, Google Auth i OpenAI będą dodawane etapami, po skonfigurowaniu sekretów środowiskowych.
